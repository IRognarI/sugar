Sugar - Приложение для контроля уровня сахара в крови

Sugar — это современное Java-приложение, созданное для удобного отслеживания и управления показателями уровня глюкозы в крови. Построенное на Spring Boot, оно предоставляет надежную серверную часть для записи, хранения и анализа данных.

✨ Основные возможности

· Запись измерений: Вносите показатели сахара с указанием времени, даты и комментариев.
· Отслеживание динамики: Наблюдайте за тенденциями и изменениями ваших показателей с течением времени.
· Backend на Spring Boot: Надежное и производительное серверное приложение.
· Чистая архитектура: Проект организован в соответствии с современными практиками разработки.

🛠 Технологический стек

· Язык программирования: Java
· Фреймворк: Spring Boot

🚀 Начало работы

Предварительные требования

· Java JDK 11 или выше
· Maven 3.6+
· Git

Установка и запуск

1. Клонируйте репозиторий
   ```bash
   git clone https://github.com/IRognarI/sugar.git
   cd sugar
   ```
2. Соберите проект
   ```bash
   mvn clean install
   ```
3. Запустите приложение
   ```bash
   mvn spring-boot:run
   ```
4. Приложение запущено и доступно по адресу (обычно http://localhost:8080).

📈 Использование

После запуска приложение позволяет:

· Добавлять новые показания глюкозы через API.
· Просматривать историю ваших измерений.
· Анализировать динамику и тенденции изменений.
