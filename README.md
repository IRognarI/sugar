## Sugar bot - Приложение для контроля уровня сахара в крови<br>

>*Sugar bot — это современное Java-приложение, созданное для удобного отслеживания и управления показателями уровня глюкозы в крови. Построенное на Spring Boot, оно предоставляет надежную серверную часть для записи, хранения и анализа данных.*

✨ **Основные возможности**

· Запись измерений: Вносите показатели сахара с указанием времени, даты и комментариев.<br>
· Отслеживание динамики: Наблюдайте за тенденциями и изменениями ваших показателей с течением времени.<br>
· Backend на Spring Boot: Надежное и производительное серверное приложение.<br>

🛠 **Технологический стек**

· Язык программирования: Java<br>
· Фреймворк: Spring Boot<br>
· Система сборки: Maven (конфигурация в pom.xml)<br>
· Контроль версий: Git<br>


**📍Установка**

1. Склонировать [репозиторий](https://github.com/IRognarI/sugar.git)<br>
***
2. Просмотреть в файле ```compose.yaml``` переменные окружения.<br>
*** 
3. Создать в корне проекта ```.env``` файл, добавить в него переменные окружения и инициализировать их.<br>
